# 云开诗词新标签页
* 打开新标签页，品读经典中国古诗词。搭配倒数日、待办事项、舒缓白噪音，在浏览间隙，记录日程。也可一键切换简洁模式，隐藏全部工具，只留清雅诗文
* 本插件是云开诗词新标签页（Legacy）的重构版本

## 简介
* 在浏览器新标签页随机展示中国古诗词
* 支持语言：简体中文
* 声明：诗词来自第三方网站，内容不代表本人的观点

## 数据来源
* 诗词来源：https://www.jinrishici.com，https://gushi.ci
* 日历来源：https://www.mxnzp.com
* 天气来源：https://v2.jinrishici.com/info

## 安装方式
* 请前往 Chrome、Edge、Firefox 等浏览器的插件商店搜索“云开诗词新标签页”进行安装
